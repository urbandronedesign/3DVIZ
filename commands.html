02Rhino 3D

Rhino is driven by typed commands more than by keys. The command line is the interface — type the first letters and it autocompletes. Aliases let you shorten anything you use often.

Rhino se pilote davantage par commandes tapées que par touches. La ligne de commande est l’interface : tapez les premières lettres et elle complète. Les alias permettent d’abréger ce que vous utilisez souvent.

Running English commands on a French Rhino

Utiliser les commandes anglaises sur un Rhino en français

If Rhino is installed in French, its commands are French too: Maillage rather than Mesh, Direction rather than Dir. That becomes a problem the moment you follow an English tutorial, or this manual.

Type an underscore in front of the command and Rhino accepts the English name, whatever language the interface is in. So _QuadRemesh works on a French installation exactly as QuadRemesh does on an English one.

Si Rhino est installé en français, ses commandes le sont aussi : Maillage et non Mesh, Direction et non Dir. L’ennui commence dès qu’on suit un tutoriel anglais, ou ce manuel.

Tapez un tiret bas devant la commande et Rhino accepte le nom anglais, quelle que soit la langue de l’interface. Ainsi _QuadRemesh fonctionne sur une installation française exactement comme QuadRemesh sur une anglaise.

Documented Documenté

McNeel’s macro documentation: the underscore “tell[s] Rhino that the command which follows is in English (no matter what the language you are running Rhino in), which will make your macro universal.”

Documentation McNeel sur les macros : le tiret bas « indique à Rhino que la commande qui suit est en anglais (quelle que soit la langue dans laquelle vous utilisez Rhino), ce qui rend votre macro universelle ».

Use the underscore even in English Mettez le tiret bas même en anglais

The underscore costs one keystroke and makes everything you write portable. An alias or a macro you build on an English machine will then still work when you sit down at a French one in the studio — and when you paste a command to a classmate, it works on their installation too. Get into the habit now rather than debugging it later.

Le tiret bas coûte une frappe et rend portable tout ce que vous écrivez. Un alias ou une macro composés sur une machine anglaise fonctionneront encore devant une machine française de l’atelier, et une commande transmise à un camarade marchera aussi chez lui. Prenez l’habitude maintenant plutôt que de déboguer plus tard.
